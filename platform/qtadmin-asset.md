# 管理后台 - 数字资产职能域

## 来源

仓库：`quanttide/qtadmin`

## asset 职能域

CLI 命令 `qtadmin asset` 提供了三个子命令，覆盖资产治理的核心环节：

| 子命令 | 功能 | 说明 |
|--------|------|------|
| `archive` | 日志归档 | 将过时资产移至 Archive |
| `status` | 结构合规检查 | 验证文件、格式、提交规范是否与契约一致 |
| `quality` | 语义质量评估 | 从叙事、知识、认知三维度评估内容质量 |

## 定位

在九宫格中属于**程序型记忆 — 规则引擎友好 × 法律层**的 Platform 资产。通过 CLI 工具将资产治理规则自动化，供规则引擎和 CI/CD 管道调用。
